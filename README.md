# Daengkuliner

Public portfolio reconstruction for an editorial guide to Makassar food culture.

## Direction

Daengkuliner is a food atlas. Instead of presenting a restaurant menu, it helps a visitor explore one dish through three lenses: ingredients, texture, and context.

## Run locally

```bash
npm install
npm run dev
```

## Build checks

```bash
npm run build
npm run test:sites
```

The imagery in `public/assets` was created specifically for this portfolio reconstruction. The content is an editorial demonstration only; it does not make live venue, menu, delivery, rating, or booking claims.
